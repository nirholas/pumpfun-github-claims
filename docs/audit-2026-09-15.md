# @pumpfunclaims production audit and repair — 2026-09-15

## Result

The channel was live, but the former mint-selection rule could publish the
wrong coin. It selected the highest-market-cap mint among all coins currently
sharing a GitHub social fee PDA. Market cap and historical PDA membership are
not transaction evidence.

The repaired pipeline decodes `DistributeCreatorFeesEvent` records in the same
transaction. It publishes a developer–coin pair only when an event names the
mint and pays the exact social fee PDA being withdrawn. Multiple evidenced
mints become separate pair events. Missing evidence stays unresolved and is not
turned into a trading alert.

Transaction `2pm12CDG5c6HxW9Mf6M1RAUd1fpNk9chaGFVDqao9Hhc7kfAEFzRCUVuzKiUrDszP8FNBRECjnNmcuwv5z9Z35kc`
was presented as BRAIN (`8XTUnXmSRP42ZVf4MyDVxAEQ6djzUpqXzywob6mLpump`).
Its distribution event actually names
`BfLgqS6vhUpAqTW5EofEB34xeo6KbBXdqRMDXbUepump`, assigns 10,000 bps of
11,286,771,447 raw quote units to the claimed PDA, and is now a committed
regression fixture.

Seven recent channel transactions were replayed. Six resolved from exact
transaction evidence. One V2 withdrawal had no matching distribution event and
now remains unpublished rather than receiving a guessed CA.

## Repairs

- Transaction-scoped mint/PDA attribution with bigint share arithmetic.
- One independent event per evidenced developer–coin pair.
- Numeric GitHub ID plus full mint duplicate keys, including legacy migration.
- Atomic `0600` claim-ledger writes and durable delivery outbox replay.
- Current (replacement) fee-share mappings rather than stale additive mappings.
- Correct Pump reserve decimal normalization and current graduated-token prices.
- Monotonic performance milestones, preventing a `5x` post followed by `2x`.

## Operational guarantees and limits

The outbox provides durable at-least-once delivery. Telegram has no
caller-supplied idempotency key, so a crash after Telegram accepts a post but
before local acknowledgement can still create a detectable duplicate.

“First” is limited to history imported into the persistent volume; cards say so
explicitly. Preserve `github-first-claims.json`,
`github-user-token-claims.json`, `github-claim-counts.json`,
`delivery-outbox.json`, and `performance-tracker.json` during deployment. Run
only one publisher.
